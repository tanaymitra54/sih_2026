01 · Problem

Fake medicine is a supply-chain failure.

~1M
deaths / year (WHO est.)

What patients face

At the pharmacy counter, look-alike packaging and paperwork give no cryptographic proof that a pack is real.

Where systems fail

Verification often asks only “does this code exist?” — not whether the signature, journey, and behaviour make sense.

02 · Gaps today

Existing tracking leaves dangerous holes.

  • Central DBs can be quietly edited
  • Static QRs can be photocopied at scale
  • “Exists” checks ignore custody history
  • No enforced factory → distributor → pharmacy order
  • Cloned genuine serials go undetected
  • Consumers rarely get a free verify path
  • Alerts are manual, late, or missing
  • Keys and audit logs lack cloud-grade controls

MedGuard attacks the last mile: make a fake hard to mint, hard to move, and hard to sell.

05 · Solution

Three trust layers on every scan.

1 · Identity

Was this pack minted? Does the signature verify?

2 · History

Is the custody chain intact and in valid order?

3 · Behaviour

Do location, timing, and scan volume look real?

One-line product thesis

A medicine is not genuine because a QR exists — it is genuine when identity, history, and behaviour all agree.

07 · Cryptographic identity

Signed QR — fingerprint, not a name tag.

Payload

MEDG:<serial>:<sig>:<batch>

Signature over serial|batch. Only the manufacturer key can mint valid packs.

Why clones fail
  • Photocopy keeps the same sticker text
  • Without the private key, new packs cannot be forged
  • Verify endpoint rejects bad signatures
08 · Ledger

Append-only blocks with two previous hashes.

flowchart TB B1[Block n-1] -->|prevHash| B2[Block n] P1[Product tip] -->|productPrevHash| B2 B2 -->|sha256 fields| H[blockHash]

Edit one row → global chain and product journey both break.

16 · Security on AWS

Trust the chain — protect the keys.

KMS

Private signing material never leaves HSM-backed keys; API signs via grants.

Cognito + IAM

Role claims map to manufacturer / admin / distributor / pharmacist.

WAF + API GW

Throttle public verify; block floods that mimic clone attacks.

Well-Architected · Security

Encryption in transit (TLS) and at rest (RDS / S3 / KMS). Separate accounts for prod. Audit with CloudTrail.
